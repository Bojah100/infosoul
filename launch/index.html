Send them all at once, with the booking sheet attached

A web page is not allowed to send mail or attach files, so bulk sending runs on your own computer, through your own mailbox. It attaches the booking sheet to every email, sends one every 45 seconds, never sends the same one twice, and copies each to your mailbox. Open a terminal in the launch-deck folder and run these in order:

shows the plan; sends nothing
sends the first one to you only
asks you to type SEND, then your mailbox password

When it finishes, press Load the sender's record and choose launch-deck-tracking.json from that folder: every email it sent is marked as sent here. Text you edited on this page is not used by the bulk sender; it sends the queue as built.

Filling the applications: autofill

The grants system is another website, so this page cannot type into it. This button can: drag it to your bookmarks bar once (press Ctrl+Shift+B if the bar is hidden).

Fill LCC application

Then, for each council:

  1. In the grants system, start the application for that council and get to the page with the questions. Copy that page's address and paste it into "My application link" for that town here, so one click brings you back.
  2. Here, open the town, open "Application answers" and press Copy all answers for autofill.
  3. Go back to the application tab and click Fill LCC application in your bookmarks bar. Allow it to read the clipboard if the browser asks. Every field it fills gets a green outline, and it lists any it could not find.
  4. Check every field, enter the budget lines by hand (they sit behind a button), attach the PDF if needed, and press Submit yourself. Nothing is submitted for you.
  5. Back here, press "Mark application submitted".

The filler matches each answer to its question by the question's wording. It was written from the state's sample application, not tested on the live form, which is behind your sign-in: look over the first one carefully.
